# Corrections and reproductions

This repository preserves observations from 28 September 2026. A later fixed page does not invalidate a dated capture, and an old capture does not prove a current defect.

For a correction, provide the affected file/finding, observation date, primary source URL, the precise field or behavior that differs, and a proposed correction. Preserve original timestamps and distinguish live observations from offline fixtures, inference and unknowns. Do not infer a global error rate from the 14-company comparison sample.

For code changes, run the offline checks in the README. Do not add target requests to CI. Keep fixtures synthetic and do not include credentials, cookies, private account records, live form submissions or mutation payloads. Passing a reproduction means the captured behavior persists in that fixture, not that a production fix has passed.

Keep source metadata, extracted/reformatted evidence and original-response hashes distinct. Rebuild the file manifest after intentional artifact edits; never replace an original-response hash with the hash of a sanitized record.

Do not open public issues containing secrets or customer data. Findings in this repository are not authorization to probe private systems or contact third parties.
